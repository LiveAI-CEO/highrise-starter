# Production Checklist

- [ ] Authorized HighRise registry credentials configured in CI and deployment.
- [ ] Private package versions resolved and lockfile committed.
- [ ] Official HighLevel context decryption wired and tested.
- [ ] OAuth state, token encryption, refresh, revocation, and uninstall flow implemented.
- [ ] Required API scopes documented and minimized.
- [ ] CSP frame ancestors validated against actual HighLevel/white-label hosts.
- [ ] Session cookies tested in embedded browser contexts.
- [ ] Lint, typecheck, unit, E2E, and production build pass.
- [ ] Secret scan and dependency review pass.
- [ ] Preview approved before production deployment.
- [ ] Rollback procedure and release notes prepared.
